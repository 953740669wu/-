# NUMA 慢域 R2 结案

**采用节点规避。** 这项四域任务可使用当前空闲且通过资源、拓扑和运行时检查的 cn21385 或 cn21386。两台均完成同机 rank 轮换，未复现历史持续慢域。cn21341 两次均未获配，历史 node1 的根因仍未确定。保留原版模型和运行库。

两台节点均独占、同 die 的物理域 0–3，共 152 核分配、144 核计算、8 核预留，DDR 98304 MB 请求、实配和原生限额一致，HBM0。原生调度回执和当前作业 cgroup 相互绑定，普通账户读取内核限额原值受限。两次提交均核对 M23/S09 和 S10 的实时节点并保持隔离。两次未获配作业没有计算进程，两个完成作业的应用清理通过，原生 PID 字段为 `-`。

每个实际作业在 4/4 域通过原严格五步，共 15580 项比较，最大绝对误差和相对 L2 均为 0。两组分别从相同初态启动，逻辑 rank 按 `[0,1,2,3] → [1,2,3,0]` 映射到物理域，启动顺序同步轮换。每组各域完成 25 步，统计第 6–25 步。各域通过实际 KML SHA、149 次原形状 SGEMM、CPU36、数据及掩码检查，最终模型 SHA 在同次作业的两组一致。保留原数值门槛和历史 FAIL。

cn21385 的步耗时极差/均值为 2.19%–5.00%，采样单域峰值 RSS 为 6764–6996 MiB。cn21386 对应 4.39%–6.82% 和 6792–6923 MiB。调度记录的整作业峰值分别为 37005 MB 和 35918 MB，swap 峰值均为 0。各域观测结束的匿名页远端驻留为 0 MiB，四组最大步开始差为 0.077 ms。各域纯训练、每步范围、完整 HWM、全 TID 绑核和页放置证据见各作业分析和原件。

cn21385 的同形状 KML 中位时间为 79.14–85.53 ms，128 MiB 本地拷贝为 6.96–7.76 ms。cn21386 对应 82.07–84.83 ms 和 8.00–8.23 ms，两台各自的四域 KML 输出 SHA 一致。cn21386 每步 149 次原生调用边界累计中位时间为 4.914–4.965 秒，其余步内时间中位为 2.570–2.798 秒。两台均有约 2 GHz 的抽样 sysfs 读数。计时边界和频率抽样无法确定原机的核心执行频率、SME 使用或带宽。

## 采用范围

历史 2061246 在 cn21341 的 node1 中位 16.631 秒，其他域约 6.93–6.94 秒，统一窗口 15.08 帧次/秒。该历史样本与新节点的结果用于判断规避是否可用，跨机变化只作现象对照。cn21341 本轮两次均停在排队，缺少该物理域的 rank 轮换、native 分解和微探针。已测两台上没有可供最小性能改动的持续异常。rank 和启动顺序同时移动，这两种因素没有独立分解。

性能候选、同机性能 A/B 和三轮确认均未启动。已接受的 HBM 配置没有可与本次节点规避在同一主机上形成配对的新设置，HBM 增量未测。缺同条件单域对照，四对一扩展效率未测。后续遇计划节点需等待时，取消已确认归属且仍 PENDING 的作业，核终态和清理后选择合格的空闲节点。

本批使用 4/8 次提交、879/14400 秒排队、1184/7200 秒分配和 35/120 秒微探针。共 480 次完整更新、30720 训练帧次，唯一 1600 帧，恢复验证额外更新为 0。两台实际分配节点已达到本批物理主机上限。旧批 5 次提交、736 秒分配和 7584 秒排队另计。当前无活动作业。
