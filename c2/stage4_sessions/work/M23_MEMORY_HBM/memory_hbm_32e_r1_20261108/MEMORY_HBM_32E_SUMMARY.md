# 09｜真实 32 电极 Encoder 内存与 HBM

**保留 HBM/CKPT12 为通过内存门的候选，暂缓作为四域速度配置采用。** 三轮同步步耗时 12.871、12.462、12.191 秒，波动 5.44%。较同轮 HBM/CKPT0 低 25.99%–29.97%，较同轮 DDR/CKPT0 低 55.77%–58.14%。每域实驻 2,894 MiB HBM，含 HBM 的每域峰值估算最高 3,722.5 MiB。单域最快为 HBM/CKPT0，DDR/CKPT12 的观测峰值最低，且无需 HBM。

原采用门要求配对速度收益至少 10%、轮间波动至多 5%。HBM/CKPT12 达到速度收益和 4 GiB 目标，波动超出 5%。前两轮慢域为 node0，第三轮为 node3，CKPT0 对照保持稳定，现有记录未定位唯一原因。剩余 1865 秒少于任一完整三组确认轮的实测分配时间。三轮均保留在统计中。

## 数值和内存来源

- M2 复用原 non-reentrant 包装对已有 12 层逐层 checkpoint。严格首步前向为反向保存的其他存储从 8,433.9 MiB 降到 761.6 MiB。KML 调用从 149 增到 197 次/更新。单域 HBM 下重算增加步时，四域 HBM 下步时下降。
- 同一分配器的四域性能段，每域大块 DDR 回退计数由 28847 降到 0。HBM arena bump 高水位约由 3.98 GB 降到 3.03 GB。申请和复用计数用于分析分配行为，未据此估计物理带宽或识别热对象。本批没有依据启动 M3。
- 原严格 5 步门全部通过。155,200 项误差指标的最大绝对误差和适用相对 L2 均为 0。另有 30,600 项 AdamW step 精确检查通过。保留 tensor abs 2e-5、state abs 2e-6、rel L2 2e-6 及原 near-zero/exact 规则。
- 真实 32_skip4 数据取自 2 个病例、8 个单元、800 帧。每次更新为 32 帧整批 fp32、928 tokens、固定初态、帧序及掩码。四域各自回放相同工程样本。正式划分与主体映射为 UNKNOWN，工程结论只覆盖所测 32 电极 B32 Encoder。有效批量始终是 B32，16 电极 B64 属于原历史批次。
