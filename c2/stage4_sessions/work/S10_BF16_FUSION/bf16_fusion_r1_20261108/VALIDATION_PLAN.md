# S10 R1 验证顺序

F 选择 Torch CPU fused AdamW。R9 job2048959 的三步优化器 wall 为 0.173312、0.173939、0.172542 秒，原阶段有 306 次 mul_ 和独立状态/参数遍历。历史剖析来自同 16 电极 B64 CKPT0 模型、DDR 配置，仅用于确定热点。copy_ 的最大项缺张量级定位。本轮不单开 profile，两个正式版本以相同的低开销时钟记录前向、反向和优化器阶段，不能由阶段计时推出纯非 GEMM 比例。

F 保持 KML、模型、输入、mask、HBM 3800 MiB 和 AdamW 参数。唯一候选逻辑是显式 fused=True，计算端先查实际 CPU dispatch 核心。优化器实现可能有舍入差异，原比较器与五步严格门先行，禁止失败后计时。门通过后同节点 fresh A/B 每侧 25 步，前 5 预热，汇总第 6–25 步中位耗时、同期峰值 RSS、HBM 驻留。单域验证后四域，同域映射和每步同步跨度；有至少 10% 整步收益再追加至同节点三对，计算每侧重复范围 / 中位数，门槛 5%。

B 等 F 单独归因后冻结底座。需要先核目标安装头文件及 sbgemm 符号，旧 83 项同输入/初权重严格逐位 fp32 控制，再逐项比较 BF16。原 P1 的 26 个 FAIL 保留。只有模块全过才执行完整模型严格五步，只有完整五步全过才运行 200 步，只有轨迹全过才计四域性能。所有门未运行按其实际阻断记录。

200 步协议提前冻结。每个 fresh 进程沿原 seed0 模型初始化后的 Torch CPU RNG，前 25 步 mask 对原 25 步 SHA，随后继续同一 RNG 生成 mask；固定原 seed0 的 1600 帧排列连续循环 8 次。只接受两侧完全相同的 200 步 frame/mask 清单，事后校验 1600 唯一帧。每步 total、voltage、coarse 独立用 abs(candidate-reference)/abs(reference) ≤1%，参考 abs≤1e-8 时绝对差≤1e-7。每步全体梯度、参数、AdamW 状态 finite，梯度存在，AdamW step 精确等于该步并记录；第200步逐参数 relL2 ≤1%，按原近零 RMS 规则。除原始逐步记录外保留两侧最后一步梯度漂移诊断。
